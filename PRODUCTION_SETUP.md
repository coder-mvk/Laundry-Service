
# A-1 Laundry CRM — Production Setup

## Requirements
- Node.js 20+
- VS Code Recommended

## Install
Open terminal inside project folder:

npm install

## Start Development Server
npm run dev

## Build Production Version
npm run build

## Preview Production Build
npm run preview

## Recommended Hosting
- Vercel
- Netlify
- Hostinger VPS
- Railway

## Recommended Future Features
- WhatsApp API Integration
